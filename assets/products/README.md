# Photos de produits

Déposez ici les vraies photos de produits (une fois disponibles), puis
référencez le nom du fichier dans le champ `"image"` du produit correspondant
dans `products.json`, à la racine du repo.

Voir `GUIDE_PRODUITS.md` pour la marche à suivre complète (comment envoyer
une photo via GitHub, sans terminal).

Tant qu'un produit n'a pas de photo (`"image": null`), le site affiche à sa
place le croquis dessiné par défaut — rien à faire de votre côté pour ça.
